# 播客智能阅读助手 v1.0.16 版本说明

发布日期：2026-08-01

v1.0.16 主要修复多位被采访者场景下，内容重构和延伸探索只围绕第一位嘉宾生成的问题。

## 内容重构

- “人物特写”和“嘉宾第一人称自述”新增嘉宾选择框。
- 当内容地图识别到多位被采访者时，用户可以明确选择本次写作对象。
- 生成请求会携带所选嘉宾，服务端会校验所选姓名必须属于被采访者名单。
- 文章缓存增加嘉宾维度；切换嘉宾、写作形式或篇幅时，不会读取另一位嘉宾的旧文章。
- “深度文章”继续面向整场访谈，并明确综合所有被采访者的观点、差异与经历。

## 延伸探索

- 为每位被采访者分别执行 Bilibili、DeepSeek Web Search 和百度百科检索。
- 每条候选结果记录对应嘉宾，AI 不允许改变资料归属。
- 结果按“关于某嘉宾”分区，再按视频播客、其他视频和文章资料分类展示。
- 若 AI 漏选某位嘉宾，系统会从该嘉宾已经验证的候选结果中自动补齐。
- 若某位嘉宾完全没有可靠结果，不保存只有部分嘉宾的不完整结果。
- 每位嘉宾必须同时具备至少一条视频或视频播客，以及至少一条文章资料；AI 漏掉类别时由已验证候选自动补齐。
- 原视频会在候选生成、AI 返回和界面渲染三个阶段重复排除，同时校验 BV 号、规范化标题和标题相似度。
- AI 输出“原视频仅作占位”之类说明时，整个项目会被直接删除，不再展示占位卡片。

## 智能稿本播放高亮

- 页面存在多个视频节点时，优先锁定当前可见且正在播放的播放器，避免播放时间源来回切换。
- 播放时间以 250 毫秒粒度推送，播放期间不再同时使用每秒轮询覆盖时间。
- 相邻段落边界增加 220 毫秒稳定区，防止红色播放指示线在两个段落之间闪烁。

## 缓存升级

- 内容重构缓存升级为 `remixV5`。
- 延伸探索缓存升级为 `followupV5`。
- 扩展更新时自动清除旧的 `remixV4`、`followupV3` 和不完整的 `followupV4` 缓存。

## 验证

- 多嘉宾文章缓存隔离测试通过。
- 多嘉宾延伸结果覆盖测试通过。
- 全部自动化测试、语法检查和生产包校验通过。

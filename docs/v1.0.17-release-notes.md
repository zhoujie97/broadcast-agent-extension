## 免费额度与用户自带 Key

- 内容地图、智能稿本 AI 理解、高光切片、内容重构、AI 提问和延伸探索，每项每天提供 2 次免费额度。
- 一次功能内部的联网搜索、人物核实和 JSON 自动修复不会重复扣除该功能次数。
- 免费额度用完后，用户可以在“AI 能力”中填写自己的 DeepSeek API Key。
- 用户配置自己的 Key 后，全部 AI 调用改用用户的 DeepSeek 账户，不再消耗免费额度。
- Key 默认保存在浏览器会话内存中；只有用户主动勾选时才持久保存在当前设备。
- Key 通过 HTTPS 临时发送给代理和 DeepSeek，代理不会把它写入数据库、日志或其他持久化存储。
- 提供 Key 测试、掩码状态展示和立即删除入口，并链接 DeepSeek 创建 Key 与充值页面。

## 悬浮面板

- 执行一次布局迁移，升级后首次打开默认贴合页面最右侧顶部，高度与页面可视窗口一致。
- 迁移后仍会记忆用户手动拖动和缩放后的布局。
- 修复 Key 安全设置误将悬浮面板页面脚本排除在布局存储之外，导致点击扩展没有反应的问题。
- 点击打开失败时不再静默忽略，扩展图标会显示错误标记，并在服务工作进程控制台记录具体原因。

# 播客智能阅读助手 v1.0.15 版本说明

发布日期：2026-08-01

v1.0.15 聚焦三个方向：人物信息准确性、智能稿本可纠错能力，以及云端 AI 的稳定性与响应速度。内容生成、人物资料和延伸探索均使用 DeepSeek，其中联网检索通过 DeepSeek Web Search 完成。

## 本次更新

### 1. 人物资料优先使用百度百科

- 人物检索优先限定到 `baike.baidu.com`，减少普通网页搜索没有返回百科条目的情况。
- 结合视频标题、发布者、字幕上下文和搜索证据判断采访者与被采访者身份。
- 移除 Wikidata 和 Wikipedia 的访问权限及结果来源。
- 当标题姓名与字幕姓名仅有少量文字差异时，必须至少获得两条独立搜索证据才会自动校字。
- 人物卡片提供百度百科条目或百度百科搜索入口；缺乏外部资料时，不再清空从字幕确认的采访角色。

### 2. 智能稿本人名可以人工修正

在“智能稿本”中展开“修正稿本人名”，填写错误姓名和正确姓名，例如：

```text
叶利静 → 易立竞
```

保存后会：

- 替换当前视频稿本中的全部命中位置；
- 按 BV 号和 CID 保存在浏览器本地，重新打开视频仍然生效；
- 同步给内容地图、高光切片、知识问答、内容重构和播放器内问答；
- 自动清除基于错误稿本生成的旧 AI 结果；
- 支持随时撤销单条修正。

人工明确指定的姓名替换不调用 AI，避免模型再次猜测。

### 3. 增加内容地图纠错入口

采访人物区域新增自然语言纠错表单。用户可以输入“张若楠应为章若楠”或“金靖不是围棋手”等问题。AI 会先结合标题、稿本和联网证据判断反馈是否成立，只有证据支持时才修改内容地图。

### 4. 高光切片增加 BGM 歌曲推荐

- 每个片段推荐 3 首真实歌曲；
- 展示正式歌名、歌手和适配原因；
- 不输出“何时切入”或“高潮处播放”等操作建议；
- 提供抖音站内搜索链接。

抖音没有向普通浏览器扩展提供歌曲音频流接口，因此本版本不抓取或直接播放抖音音乐。

### 5. AI 调用性能优化

- 人物资料生成和身份复核合并为一次 AI 调用；
- 人物姓名搜索并行执行；
- 人物资料与缺失年份补充并行执行；
- 相同联网搜索结果缓存 30 分钟；
- 不同功能使用独立的字幕输入预算；
- JSON 结构校验失败时只修复已有结果，不再携带整份稿本重新生成；
- DeepSeek 使用非思考模式，减少结构化内容任务的额外等待。

输入预算只会影响超过上限的超长稿本。普通视频未超过限制时仍会使用完整稿本。

### 6. 扩展 Origin 和代理安全

- 支持配置固定 Chrome 扩展 Origin；
- 侧载测试阶段可使用 `chrome-extension://*`，但它只匹配格式合法的 Chrome/Edge 扩展 Origin，不允许普通网页；
- 增加匿名安装会话、每分钟额度、单安装每日额度和全局每日额度；
- API Key 只保存在 Vercel 环境变量中，不进入扩展源码和安装包。

正式上架后建议把 Origin 通配符改成商店分配的固定扩展 ID。

## 系统组成

| 能力 | 当前服务 |
| --- | --- |
| 内容地图、切片、问答、重构、纠错 | DeepSeek `deepseek-v4-flash` |
| 百度百科人物检索、延伸探索 | DeepSeek Web Search |
| API Key 与访问控制 | Vercel HTTPS 代理 |
| 稿本修正、笔记、AI 结果缓存 | 浏览器本地存储 |

## Vercel 环境变量

生产代理至少需要以下配置：

```text
AI_MODEL=deepseek-v4-flash
DEEPSEEK_API_KEY=你的 DeepSeek API Key
SESSION_SIGNING_SECRET=至少 24 字符的随机字符串
ALLOWED_EXTENSION_ORIGINS=chrome-extension://你的正式扩展ID
```

侧载测试时可以临时使用：

```text
ALLOWED_EXTENSION_ORIGINS=chrome-extension://*
```

生产代理地址：

```text
https://broadcast-agent-extension.vercel.app
```

健康检查：

```text
https://broadcast-agent-extension.vercel.app/health
```

## 构建安装包

在仓库根目录执行：

```bash
API_BASE_URL=https://broadcast-agent-extension.vercel.app \
RELEASE_VERSION=1.0.15 \
npm run package:extension
```

生成文件：

```text
dist/extension/
dist/broadcast-agent-extension.zip
```

## 本地安装或升级

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择 `dist/extension/`。
5. 已安装旧版本时，点击扩展卡片上的“重新加载”。
6. 刷新已经打开的 Bilibili 视频页面。
7. 旧内容地图缓存会自动失效；点击“生成内容地图”获得新版人物资料。

## 已知限制

- AI 字幕本身仍可能识别错字，需要用户使用稿本人名修正功能；
- 百度百科存在同名人物时，系统会结合视频上下文筛选，但不确定资料仍可能被省略；
- 抖音歌曲仅提供站内搜索跳转，不提供内嵌试听；
- Vercel 无状态实例中的进程内限额不是跨实例强一致计数，正式大规模发布时建议接入持久化限流存储。

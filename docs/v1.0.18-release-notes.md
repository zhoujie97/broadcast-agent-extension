# 播客智能阅读助手 v1.0.18 版本说明

## 界面调整

- 将“智能稿本”移到“内容地图”之前，并设为默认打开的工作区。
- 精简“AI 能力”区域，移除模型就绪提示和 Key 存储方式的冗余括注。
- 免费额度用完后使用与插件一致的弹窗提示；每个功能每天免费使用 2 次。

## 内容可靠性

- 人物轨迹不再展示“年9月”“9月”等缺少四位年份的月份。
- 清理无证据年份时会同时移除其月份和日期，避免产生残缺时间。
- 流式传输未完整结束时自动切换安全模式重试，并保留中断原因用于诊断。

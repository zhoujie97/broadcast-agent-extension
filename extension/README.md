# 播客智能阅读助手

这是一个用于验证 Bilibili 智能稿本读取、播放器跳转、视频内笔记与 AI 阅读工作区的 Manifest V3 扩展。

## 已实现

- 读取当前 Bilibili 视频的中文字幕轨和时间戳
- 将逐句字幕合并为适合阅读的采访发言段落，并按停顿、问句和语气补充中文标点
- 点击时间戳跳转播放器，播放时高亮当前段落
- 播放器消息接收端缺失时自动重新注入页面脚本并重试
- 搜索、复制完整智能稿本
- 智能稿本滚动超过一定距离后显示“返回顶部”按钮
- 通过安全代理调用智谱 `glm-4.7-flash`
- 在智能稿本中选中文字即可查看结合前后文的一段式 AI 解释
- “内容地图”把采访划分为可跳转主题章节，完整展示采访视频封面，并分别展示采访者、被采访者的联网核实资料
- “高光切片”是 AI 内容价值分析层，从完整采访中识别 8 至 10 个具有传播价值、认知价值和二次创作价值的关键节点
- 关键节点按情绪共鸣、认知突破、金句传播、故事高潮、争议观点分类，并展示情绪冲击、观点价值、内容完整性、独立传播性、传播潜力五维评分与逐项依据
- 结果默认按综合内容价值排序，支持按类型筛选、内容价值画像，以及面向短视频和文章的场景建议与推荐标题
- 候选节点支持时间戳跳转、区间循环预览、收藏与批量复制；原声摘录和时间边界会与真实字幕核对
- 内容地图每个主题章节使用一段连贯正文表达，不再把观点拆成项目符号
- 人物资料优先使用本人、政府、奥运组织、机构官网和权威媒体来源；只展示稳定身份与代表性成就，不再写近期综艺阵容或参加年份
- 人物资料结构化生成失败时自动降级为可追溯的搜索摘要与原始来源，避免整卡只显示“暂无”
- 智谱搜索无结果时再使用 Wikidata 与中文维基百科公开资料兜底；内容地图中的年份若未在标题、视频简介或智能稿本中出现，会被自动删除
- “内容重构”可生成用户选择的人物特写、杂志报道、传记片段、第一人称自述或观点文章
- 播放器内悬浮“记笔记”按钮会读取真实播放时间，在 Bilibili 全屏播放器内也可使用
- “知识笔记”支持基于完整采访问答，并把答案和引用时间点自动写入笔记
- “延伸探索”通过智谱网页搜索查找相关播客、视频、文章和人物资料，并只展示经过候选链接白名单校验的 URL
- 延伸探索在智谱检索无结果时自动尝试 Bilibili 视频搜索与公共知识库，全部失败时仍提供可点击的 Bilibili 搜索入口
- 延伸探索会按当前 BV 号和标准化标题双重排除本期原视频
- 用户无需下载本地模型，也无需输入 API Key

## 为什么必须使用代理

浏览器扩展的源代码和网络请求对用户可见，任何写入扩展的 API Key 都可以被复制。为了让用户免输入 Key，扩展只请求你部署的代理；智谱 Key 只存在于代理服务的环境变量中。

源码开发版默认代理地址为：

```text
http://127.0.0.1:8787/v1/chat/completions
```

生产发布使用根目录的 `npm run package:extension`。构建脚本会自动写入 HTTPS 代理地址与对应域名权限，并检查本地地址和疑似密钥，详情见根目录 `DEPLOYMENT.md`。

## 启动本地代理

要求 Node.js 18 或更高版本。

```bash
ZHIPU_API_KEY="你的智谱API Key" npm run proxy
```

密钥只通过环境变量传入，不要写入代码或提交到 Git。默认模型由 `AI_MODEL` 配置，当前为 `glm-4.7-flash`；可通过 `AI_FALLBACK_MODEL` 配置备用模型。

代理健康检查：

```text
http://127.0.0.1:8787/health
```

## 侧载到 Edge

1. 启动 GLM 代理。
2. 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择本目录 `extension/`。
5. 如果扩展已经加载，点击“重新加载”。从 WebLLM 版本升级时，扩展会自动删除旧模型缓存。
6. 登录 Bilibili 并打开普通视频页。
7. 点击扩展图标，在视频网页上打开悬浮阅读面板；再次点击可以隐藏。
8. 悬浮面板默认宽约 640px，可拖动标题栏移动，也可拖动左边缘调整宽度。
9. 视频右上角的圆形“？”支持记笔记和在当前时间点提问；悬浮时显示时间和两个操作，AI 回答会以适配播放器尺寸的小卡片显示，并自动写入知识笔记。
10. 主悬浮面板最小化后会变为页面右侧中部的“播”字圆点，与播放器问号入口分开。
11. 每次重新加载扩展后，刷新已打开的 Bilibili 视频页，以载入最新悬浮面板和视频内问号按钮。
9. 在智能稿本中选中文字查看 AI 理解。

## 统一 AI 入口

段落解释、内容地图、高光切片、内容重构、知识笔记问答和延伸探索的内容筛选全部调用 `extension/background.js` 中的 `callAiJson`。扩展不决定具体模型，模型由代理环境变量 `AI_MODEL` 统一指定；切换兼容模型时无需重新发布扩展，健康检查会把新模型名称同步到悬浮面板。

人物资料和延伸探索通过同一代理的 `/v1/web-search` 调用智谱网页搜索。搜索服务与对话模型可能分别计费或受独立额度限制，请在智谱控制台确认当前规则。

笔记、内容地图、高光切片、延伸探索结果和生成文章保存在 `chrome.storage.local`，按视频 BV 号和 CID 隔离；AI 问答笔记会同时保存可点击的引用时间点。

## 生产部署要求

- 使用 HTTPS 代理地址。
- 把 `ZHIPU_API_KEY` 设置为服务端 Secret。
- 将 `ALLOWED_EXTENSION_ORIGINS` 限制为正式扩展的固定 Origin。
- 代理已包含注册频率、每分钟、单安装日用量和全局日用量限制；上线后仍需在平台监控请求量、429 与上游错误。
- 不记录完整字幕、Authorization 请求头或模型回复。

仅依赖 CORS 不能防止代理被滥用；公开发布前必须增加服务端限流和预算保护。免费模型也可能有并发、频率或平台政策限制。

## 隐私边界

- 扩展不读取、保存或上传 Bilibili `SESSDATA`。
- 登录态只用于扩展后台向 Bilibili 发起字幕读取请求。
- 只有用户点击 AI 功能时，相关字幕才会发送到你的代理及智谱 API。
- 生成人物资料或延伸探索时，视频标题、人物名和主题关键词会发送到智谱网页搜索。
- 用户端不保存智谱 API Key。
- 段落解释结果只缓存在当前浏览器会话。

## 常见失败

### 无法连接 GLM API 代理

- 本地验证时确认 `npm run proxy` 正在运行。
- 确认代理健康检查能返回 `{ "ok": true }`。
- 生产环境确认 `AI_PROXY_URL` 和 `host_permissions` 使用同一 HTTPS 域名。

### 智谱返回 401 或 403

检查代理环境变量中的 `ZHIPU_API_KEY` 是否有效。不要把 Key 发到聊天、截图、日志或扩展代码中。

### 字幕无法读取

确认登录发生在当前 Edge 配置文件中，刷新视频页后重试。部分视频可能没有可用的中文或 AI 字幕轨。
